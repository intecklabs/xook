# Política de privacidad de Xook

**Última actualización: 11 de septiembre de 2026**

Xook es un lector de libros (PDF y EPUB) para Windows y Android desarrollado por Inteck. Esta política explica qué datos maneja la aplicación.

## Qué datos se guardan y dónde

- **Tus libros, notas, subrayados, progreso de lectura y ajustes** se guardan únicamente en tu dispositivo (en el almacenamiento privado de la app en Android; en tu carpeta de datos en Windows). Xook no tiene servidores propios y **no sube tu biblioteca ni tus datos a ningún lugar**.
- Xook **no requiere cuenta**, no pide tu nombre, correo ni contraseña, y no usa herramientas de análisis, publicidad ni rastreo.

## Conexiones a internet

Xook solo se conecta a internet para funciones concretas que tú activas, y solo envía lo mínimo necesario:

| Función | Servicio | Qué se envía |
|---|---|---|
| Portadas automáticas | Open Library (Internet Archive) y Google Books | Título y autor del libro |
| Diccionario | Wikcionario, Wiktionary y Wikipedia (Wikimedia) | La palabra consultada |
| Narrador con voces neuronales (solo Windows) | Servicio de voz de Microsoft Edge | El fragmento de texto a leer en voz alta |
| Actualizaciones (solo Windows) | GitHub | Número de versión instalada |

En Android, el narrador usa las voces instaladas en el teléfono y no envía texto a internet.

Estos servicios de terceros reciben tu dirección IP como parte de cualquier conexión web y aplican sus propias políticas de privacidad. Puedes usar Xook sin conexión: todas las funciones de lectura funcionan sin internet.

## Envío por correo (solo Windows)

Si configuras el envío de libros a Kindle o a otro dispositivo, tu contraseña de correo se guarda cifrada en tu equipo mediante las funciones de seguridad de Windows y solo se usa para conectarse al servidor SMTP que tú indicas.

## Permisos en Android

- **Archivos**: se usan únicamente para abrir los libros que tú eliges con el selector del sistema. Xook no explora ni lee otros archivos.
- **Internet**: para las funciones opcionales descritas arriba.

## Menores

Xook no recopila datos personales de ningún usuario, incluidos menores de edad.

## Eliminación de datos

Como todo se guarda en tu dispositivo, para borrar tus datos basta con desinstalar la app (Android) o eliminar la carpeta de datos (Windows, ver Configuración → Carpeta de datos).

## Cambios

Si esta política cambia, se actualizará este documento y la fecha indicada arriba. La versión vigente siempre está en https://github.com/intecklabs/xook/blob/main/PRIVACY.md
